# Research

## Explainable Imbalance-Aware Facial Emotion Recognition

**First Author | NIELIT Delhi**

Research work focused on improving facial emotion recognition under severe class imbalance.

- Developed a facial emotion recognition framework using **ConvNeXtV2-Tiny**
- Applied transfer learning and self-supervised FCMAE pretraining
- Used **Class-Weighted Focal Loss** for class imbalance
- Integrated **Grad-CAM** for model explainability
- Achieved **0.94 Macro-F1**
- Achieved **0.91 F1-score for the Fear class**
- Compared performance with CNN-based benchmark architectures

**Research Areas:**  
Computer Vision • Deep Learning • Explainable AI • Facial Emotion Recognition
